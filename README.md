# Mindmark — IQ-тест

MVP веб-сервиса IQ-тестов с подписочной монетизацией. Воронка: главная → тест → расчёт → paywall → оплата → результат.

Рабочая версия: https://iq-mindmark.vercel.app

## Стек

- Next.js (App Router), TypeScript, Tailwind CSS
- Convex — база данных и серверные функции
- Vitest + convex-test — тесты серверной логики
- Vercel — хостинг

## Запуск

```bash
npm install
npm run dev
```

Команда поднимает Convex и Next.js, приложение откроется на http://localhost:3000.

## Проверки

```bash
npm test
npm run typecheck
npm run lint
```

## Экраны

| Адрес | Что на экране |
|---|---|
| `/` | Главная: предложение пройти тест, первое задание прямо на странице, FAQ |
| `/quiz` | 20 вопросов: фигуры-матрицы, числовые ряды, аналогии, логика |
| `/analyzing` | Расчёт результата |
| `/paywall` | Результат готов, но скрыт; предложение оформить доступ |
| `/checkout` | Имитация оплаты |
| `/result` | Балл IQ, место среди участников, разбор по навыкам |
| `/cancel` | Отмена подписки по email |
| `/legal` | Документы |

## Как устроен paywall

- Правильные ответы хранятся только на сервере (`convex/lib/questionBank.ts`) и не попадают в браузер.
- IQ считается на сервере при завершении теста.
- `attempts.result` отдаёт балл только после записи об оплате; `markPaid` — внутренняя функция, с клиента её вызвать нельзя.
- Оплата имитируется: платёж сохраняется в таблицу `payments`, деньги не списываются.
- Подписчик проходит тест повторно без новой оплаты, пока подписка не отменена.

## Данные

- `attempts` — попытки: ответы, балл, статус оплаты.
- `payments` — платежи: сумма, email, статус, отметка об отмене подписки.
- `events` — события воронки: просмотр главной, клики по кнопкам старта с источником, старт и завершение теста, просмотр paywall, оплата, просмотр результата.
